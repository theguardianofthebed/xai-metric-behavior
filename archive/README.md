# Historical Phase 1 archive

The earlier experiment source, configuration files, notebook, viewer, tests, and documents are preserved in [`phase1/`](phase1/), with their original relative structure and file contents. They come from `main` commit [`cd3cdfd85b89155774d2d8879439ef2bca455f6e`](https://github.com/theguardianofthebed/xai-metric-behavior/commit/cd3cdfd85b89155774d2d8879439ef2bca455f6e), inspected before the EXP-01 restructuring.

The archive contains the earlier oracle/learned-XAI runners, configurations, Colab notebook, Streamlit viewer, tests, and documentation. Its old quick-start commands and package requirements describe that historical scaffold. They are not the entry points for the current experiment.

This material has **not been rerun as part of the restructure**. Existing status text and previous pilot observations are retained for provenance; they do not verify the current Atlas protocol. In particular, old preprocessing, target handling, aggregation, or Quantus compatibility patches must not be silently inherited by EXP-01.

For current work, return to the [repository README](../README.md), [research framework](../docs/FRAMEWORK.md), and [EXP-01 design](../docs/EXP-01.md). Git history also retains the original layout.
